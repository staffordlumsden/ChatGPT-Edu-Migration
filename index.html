Step 01 · Extract

Ask each AI what is worth carrying forward.

Use the same prompt in each AI assistant you use. Each one creates a short personal-harness file containing the durable context worth carrying forward.

What you are doing
01

Create one personal-harness file per AI tool

Paste the prompt into each AI assistant that knows you well. Save each response as Markdown or plain text.

Why this works

Each AI may know a different part of your context. Using one prompt makes the outputs easy to combine in the next step.

Important limitation

An assistant may not be able to see your full history or memory. The prompt explicitly tells it not to invent inaccessible information.

Universal extraction prompt
Use this in each source AI
When you have two or more outputs, do not concatenate them manually. Reconcile them.

The extraction prompt privileges durable context and explicit user statements. It deliberately separates global working preferences from temporary or project-specific information.

Step 02 · Reconcile

Turn several versions of “you” into one source of truth.

Choose one AI tool as your workspace. Add the harness files from Step 1 and run the prompt to combine them into one clean Master Harness.

What you are doing
02

Create the Master Portable Personal Harness

Attach or paste all of your Step 1 harnesses, then run the reconciliation prompt. Review any conflicts it flags and save the result.

Why not just merge the files?

Reconciliation removes duplication, keeps useful differences and flags genuine conflicts instead of guessing.

Use your preferred AI tool or surface
Merge & reconciliation prompt
Use with all Stage 1 outputs
The Master Harness becomes your platform-neutral source of truth. Keep a copy outside any single AI service.

This stage is the epistemic checkpoint: explicit information, repeated evidence, inference and conflict are treated differently. The user remains the final authority.

Step 03 · Integrate

Give ChatGPT Edu the smallest useful version of your context.

Move the durable parts of your Master Harness into ChatGPT Edu. ChatGPT will tell you whether your workspace can use them persistently.

What you are doing
03

Move your durable context into ChatGPT Edu

Open ChatGPT Edu, attach or paste the Master Harness, then run the integration prompt. Keep temporary or project-specific material out of persistent personalisation.

Persistence is workspace-dependent

Memory and personalisation depend on workspace settings. If persistence is unavailable, ChatGPT should give you one clear next step.

Before you integrate

Do not migrate secrets, credentials or material you would not want governed by your institution's workspace policies.

ChatGPT Edu integration prompt
Use with the Master Harness
A successful migration should be recognisable, not merely reported as “done”. Test it in a fresh chat.

The destination is not a dump of the old archive. It is a compact, durable layer that allows the new system to respond appropriately from the start.

Step 04 · Recognise

Start a fresh chat. Does it still feel like your ChatGPT?

The clean-room check tests whether useful personal context survived beyond the migration conversation. If it did, ChatGPT should be able to describe how it understands you without reconstructing that information from the current thread.

I understand who you are

Core professional or personal context is accurate and current.

I understand how you work

Strong interaction and evidence preferences are visible.

I understand your voice

The description is specific enough to be recognisable to you.

I act differently

Concrete response behaviours follow from the migrated context.

The test is intentionally simple

If the output feels generic, incomplete or wrong, do not keep adding more history. Correct the Master Harness or the persistent personalisation layer, then test again.
